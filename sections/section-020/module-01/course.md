# Working With A Cluster

This module develops the reasoning needed to explain how a kubeconfig context selects a cluster and identity.

## Learning Goals

- Explain how a kubeconfig context selects a cluster and identity.
- Choose resource, event or log evidence for a diagnostic question.
- Compare declarative apply with imperative operations.
- Predict how deletion interacts with workload controllers.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
