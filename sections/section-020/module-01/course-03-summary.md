# Summary

A kubeconfig context selects a cluster, credentials and a default namespace. The API server still controls permissions. Resource fields, events and application logs provide different kinds of evidence.

Declarative configuration records desired state, while imperative actions request specific changes. Controllers determine what happens after a managed Pod is deleted. Accepted changes and deletion requests need follow-up observation because reconciliation, termination and dependency handling take time.
