# Operating Kubernetes

This module develops the reasoning needed to compare managed and self-managed operating responsibilities.

## Learning Goals

- Compare managed and self-managed operating responsibilities.
- Explain control plane availability and datastore recovery.
- Distinguish application availability from control plane availability.
- Describe how custom resources and Operators extend Kubernetes.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
