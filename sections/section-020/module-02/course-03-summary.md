# Summary

ConfigMaps hold non-sensitive settings; Secrets hold sensitive data that still requires access and storage protection. Environment variables and mounted files have different update behavior, and applications may need to reload or restart.

Requests influence scheduling; limits constrain runtime use. ResourceQuota controls aggregate namespace budgets, while LimitRange supplies defaults and per-resource constraints. Admission success, successful placement and healthy execution remain separate outcomes.
