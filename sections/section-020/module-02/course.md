# Configuration And Resource Management

This module develops the reasoning needed to choose ConfigMap or Secret for application configuration.

## Learning Goals

- Choose ConfigMap or Secret for application configuration.
- Explain how configuration changes reach a running container.
- Distinguish resource requests from limits.
- Compare ResourceQuota with LimitRange.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
