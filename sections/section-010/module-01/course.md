# Cluster Architecture

This module develops the reasoning needed to identify the control plane components and their responsibilities.

## Learning Goals

- Identify the control plane components and their responsibilities.
- Distinguish node agents from cluster controllers.
- Trace a workload request from storage to container execution.
- Explain how reconciliation restores a declared replica count.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
