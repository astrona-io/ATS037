# Pods And Their Lifecycle

This module develops the reasoning needed to explain which resources containers share inside a Pod.

## Learning Goals

- Explain which resources containers share inside a Pod.
- Distinguish Pod phases from container states and waiting reasons.
- Compare readiness, liveness and startup probes.
- Distinguish a container restart from Pod replacement.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
