# Summary

API versions and kinds describe resource types. Metadata identifies and organizes objects, specifications describe intent, and status reports observed progress. Namespaced and cluster-scoped resources have different naming boundaries.

Labels and selectors identify groups without depending on individual names. Annotations carry other metadata. Owner references establish lifecycle relationships, which remain distinct from traffic selection. Recreating an object creates a new identity even when its name is reused.
