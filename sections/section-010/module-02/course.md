# Kubernetes API And Resources

This module develops the reasoning needed to read the purpose of an object's API version, kind, metadata and specification.

## Learning Goals

- Read the purpose of an object's API version, kind, metadata and specification.
- Distinguish namespaced resources from cluster resources.
- Explain labels, selectors and annotations.
- Identify owner relationships and object identity.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
