# Workload Controllers

This module develops the reasoning needed to choose Deployment, StatefulSet or DaemonSet for a workload.

## Learning Goals

- Choose Deployment, StatefulSet or DaemonSet for a workload.
- Explain the Deployment and ReplicaSet relationship.
- Compare a Job with a CronJob.
- Identify what controllers do and what application logic must still do.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
