# Scheduling Decisions

This module develops the reasoning needed to explain scheduler filtering and scoring.

## Learning Goals

- Explain scheduler filtering and scoring.
- Compare required placement rules with preferences.
- Distinguish node affinity from Pod affinity.
- Predict the effect of taints and tolerations.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
