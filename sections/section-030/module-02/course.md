# Placement And Scaling

This module develops the reasoning needed to explain why a resource request can leave a Pod Pending.

## Learning Goals

- Explain why a resource request can leave a Pod Pending.
- Distinguish replica changes from node capacity changes.
- Explain the Horizontal Pod Autoscaler feedback loop.
- Relate placement and disruption handling to application availability.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
