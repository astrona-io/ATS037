# Scheduling

This section teaches scheduling decisions; placement and scaling. These ideas help you explain system behavior and choose a suitable approach in a KCNA scenario.

You will work through Scheduling Decisions, Placement And Scaling. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. An original YAML question bank is prepared for the end of the section, with answer explanations for future quiz integration.

## Learning Outcomes

- Explain scheduler filtering and scoring.
- Compare required placement rules with preferences.
- Distinguish node affinity from Pod affinity.
- Predict the effect of taints and tolerations.
- Explain why a resource request can leave a Pod Pending.
- Distinguish replica changes from node capacity changes.
- Explain the Horizontal Pod Autoscaler feedback loop.
- Relate placement and disruption handling to application availability.
