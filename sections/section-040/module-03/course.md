# Container Application Design

This module develops the reasoning needed to explain command, arguments and environment settings at startup.

## Learning Goals

- Explain command, arguments and environment settings at startup.
- Choose durable storage for application state.
- Distinguish init containers from sidecar patterns.
- Explain graceful termination and safe workload replacement.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
