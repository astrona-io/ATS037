# Containers And Isolation

This module develops the reasoning needed to describe how namespaces and cgroups affect Linux processes.

## Learning Goals

- Describe how namespaces and cgroups affect Linux processes.
- Compare container isolation with virtual machine isolation.
- Explain the container runtime's role.
- Distinguish the CRI from image and runtime standards.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
