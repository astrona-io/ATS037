# Summary

Images package files and runtime configuration, often through reusable layers. Containers add writable state without changing the published artifact. Tags are mutable references, while digests identify content.

Build, publication and pull are separate operations. Registry access, credentials, artifact existence and platform compatibility all affect startup. Smaller runtime images can reduce unnecessary components, but security still needs dependency and privilege checks.
