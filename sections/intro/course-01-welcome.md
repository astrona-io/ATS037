# Welcome To The Course

This course is for learners preparing for the Kubernetes and Cloud Native Associate (KCNA) examination. It covers Kubernetes Fundamentals, worth 44% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations build the reasoning needed to choose an answer and explain why the alternatives do not fit.

At the end, you can explain and compare the concepts in Kubernetes Core Concepts, Administration, Scheduling, Containerization. Technical terms and acronyms are defined when they appear. Examples use ordinary applications; names such as `scout` and `probe` identify workloads rather than changing the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching lessons and ends with a summary. Read the examples carefully, identify which component does the work, and predict what changes when a condition changes.

Original practice questions are prepared as reusable YAML banks at section checkpoints and at the end of the domain. They can be presented by a future quiz interface with answer feedback. The current reading manifest contains the teaching pages; the question data is kept separately for integration. These exercises are not copied from the examination.
