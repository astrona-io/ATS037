# Welcome To The Course

This course is for learners who prepare for the Kubernetes and Cloud Native Associate (KCNA) examination. It covers Kubernetes Fundamentals, which is 44 percent of the published curriculum. The examination asks multiple-choice questions, so the lessons build the reasoning that you need to pick an answer and to explain why the other options do not fit. The hands-on parts let you see each mechanism on a real cluster before you reason about it.

## Who this course is for

You have seen a container and a terminal, and you can type a command. You do not need earlier Kubernetes experience. Each technical term and acronym is defined where it first appears. The examples use ordinary applications. Names such as `scout`, `probe` and `shuttle` identify example workloads and do not change the technical meaning.

## What you can do at the end

You can explain and compare the concepts of four examination objectives:

- **Kubernetes Core Concepts.** Name the components of a cluster, follow a request through them, read objects, labels and Pod lifecycle evidence, and choose the right workload controller.
- **Administration.** Work with contexts and declarative changes, deliver configuration, set requests, limits and quotas, and describe how operators and custom resources extend the cluster.
- **Scheduling.** Predict where a Pod runs from selectors, taints, tolerations and capacity, and explain how autoscaling and disruption budgets protect availability.
- **Containerization.** Describe how Linux isolates a container, how images, tags and digests work, and how init containers and sidecars shape an application.

## How the pages fit together

The course has four sections, one for each objective. A section has several modules. A module has this order: a landing page that states the problem and the goals, two or three lessons, a graded lab and a summary. Every landing page ends with a button that starts a Playground, which is a small Kubernetes cluster on your own machine. You keep it next to the lesson and run the commands as you read. After the last module of a section you solve a capstone lab that combines the modules, and then you take a knowledge check of single-choice questions. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. Then run the commands and compare the result with your prediction. The practice questions are original and are not copied from the examination.
